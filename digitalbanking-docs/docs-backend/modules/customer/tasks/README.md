## Dependency report to lead

1. Identity + DB owner: ai tạo Customer row khi tạo `app_user` loại CUSTOMER; migration FK và version Flyway nào dùng?
2. API + BA + Security: chốt mask `fullName` khi staff tra cứu, và chính sách truy cập theo data scope. **Cập nhật 17/11/2026:** thuật toán mask tạm đã có (DEC-CUS-005, `PiiMaskingUtils.maskFullName`) — vẫn cần owner chốt oracle; data-scope vẫn BLOCKED (CUS-OI-05).
3. Common + Identity: principal propagation thật đã PASS qua opaque session pipeline; `Session.customerId` vẫn `null` thuộc owner Identity nhưng Customer resolve authoritative qua `CustomerQuery`.
4. Audit + Admin: permission `CUSTOMER_READ`, client metadata bypass và C3 trace/failure policy đã PASS. Durable `AuditModuleApi`/`audit_log` và staff data-scope CUS-OI-05 vẫn BLOCKED; AUDITOR seed vs 07 §8.2.4 chờ owner phân xử.
5. BA + DB: xác nhận có mở rộng national ID/CIF/KYC hay giữ schema chuẩn; hiện tại **không thêm**.
6. Account + Transfer: chính sách `INACTIVE` và CustomerQuery snapshot ảnh hưởng đến giao dịch; không giả định KYC.
